# Qwertycoin GUI v2.0.6

## Source and dependency

GUI product version: `2.0.6`. The release pins Core source
`d37b3efdab56171d888a0239566d54bbb436d14f`, with Core product version `2.0.6`
and legacy hardware/ZMQ compatibility version `2.0.6.0`. Every package must
record this exact Core Gitlink and the final merged GUI source revision in
`BUILD-INFO.txt`.

The pinned Core contains the merged EPoSE epoch-46 receipt-retention and
epoch-47 admission-delivery fixes, bounded service-endpoint DNS resolution,
and the current finalized epoch checkpoints. The GUI observes these outcomes
through Core RPC and does not implement consensus or service-node qualification
logic. Local producer flags, network/genesis-bound keystore paths,
remote-node observation-only behavior, and the updater trust contract remain
unchanged. This version update introduces no GUI-side consensus or wallet
format change.

## Release gates and limitations

Native candidates use one immutable merged GUI source and the exact Core
Gitlink above: Linux x86_64, Windows x86_64, then macOS Apple Silicon. Required
GUI/QML/EPoSE/updater CI, package provenance, runtime/dependency smoke, Windows
installer data-preservation checks, and macOS copied-app smoke remain required.
Assembly verifies the successful platform candidates before publishing the
five native packages and `SHA256SUMS`.

This is a public-test client release. The EPoSE audit/readiness gate remains
`no-go` (0/13); it is not an audit-readiness claim. Linux and Windows artifacts
are unsigned. macOS ARM64 is ad-hoc signed, not Developer ID signed or
notarized. Hardware-wallet support remains unvalidated and fail-closed.
