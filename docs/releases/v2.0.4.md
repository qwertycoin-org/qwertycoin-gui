# Qwertycoin GUI v2.0.4

## Source and dependency

This release advances the GUI version from 2.0.3 to 2.0.4 and pins the official
Core v2.0.4 commit `1e479cc9feda48e07dd07ba6abcb89ca3934b5e2`.
The GUI source revision is recorded in every package's `BUILD-INFO.txt` and in
the published release notes.

The Core update includes the 2026 DNSSEC trust-anchor refresh, finalized EPoSE
epoch checkpoints, and display-only EPoSE node telemetry. The GUI wallet API,
network identity, address formats, and existing wallet storage remain
unchanged. RandomX continues to secure block production and chain selection;
EPoSE remains a service-reward mechanism.

The unmerged QMS Messenger work is not part of this release. The bounded,
HTTPS-only release-asset redirect support from the published v2.0.3 is retained.

## Release verification

Native release candidates are built in this order: macOS Apple Silicon,
Windows x86_64, then Linux x86_64. Each uses the same immutable GUI source and
Core pin, with development mode disabled and the updater enabled.
The existing release assembly verifies all three native runs, package
provenance, archive contents, and checksums before publishing the five native
packages and `SHA256SUMS`.

Compatibility and signing limitations remain unchanged:

- macOS Apple Silicon requires macOS 15 or newer; the app is ad-hoc signed,
  not Developer ID signed or notarized.
- Windows offers an unsigned installer and portable ZIP.
- Linux x86_64 targets a GLIBC 2.35 ceiling and is unsigned.
- Hardware-wallet support remains unvalidated and fail-closed.
- Core EPoSE public-test/audit-readiness limitations are not removed by this
  GUI release.
