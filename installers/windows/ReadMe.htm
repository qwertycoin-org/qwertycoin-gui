This package contains the Qwertycoin desktop wallet, the Qwertycoin daemon and command-line wallet tools. The wallet uses the Qwertycoin v2 network and the qwertycoin: payment URI.

Back up your wallet

Write the 25-word recovery phrase on paper and keep it offline. Never enter it into a website and never send private keys to support staff.

Local or remote node

A local qwertycoind provides independent verification and the strongest privacy. A remote node can observe wallet requests and must be selected deliberately. Initial local synchronization may take time.

EPoSe

EPoSe service operation is opt-in and separate from RandomX mining. It requires a continuously reachable restricted-RPC probe endpoint, a public primary QWC reward address and a Core-managed service keystore. It never requires a wallet private spend key or private view key.
