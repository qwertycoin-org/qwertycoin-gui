# Security policy

Security fixes target the latest published Qwertycoin GUI release and current
`master`. Report vulnerabilities privately through GitHub's **Report a
vulnerability** form in this repository's Security tab; do not open a public
issue.

Include the exact GUI revision, pinned Core revision, platform, reproduction
steps, and impact. Never attach wallet seeds, spend keys, wallet files,
service-node private keys, or production credentials.

Wallet-funds, key-handling, update-integrity, embedded-Core, RPC-exposure, and
remote-code-execution reports receive the highest priority. Historical GUI
builds and the legacy pre-v2 network are unsupported.
